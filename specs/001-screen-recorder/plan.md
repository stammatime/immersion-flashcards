# Implementation Plan: Screen Recorder

**Branch**: `001-screen-recorder` | **Date**: 2026-04-12 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/001-screen-recorder/spec.md`

## Summary

A cross-platform desktop application (Windows 10+ and macOS 12+) that lets the user record
their screen, control where recordings are saved, and select which display to capture — all
from a simple single-window UI. Built in Python 3.11 with PyQt6 for the GUI and FFmpeg
(bundled) for capture and encoding. This is the foundational capture layer for the future
subtitle-extraction and flashcard-creation pipeline.

## Technical Context

**Language/Version**: Python 3.11+
**Primary Dependencies**: PyQt6 (GUI), FFmpeg 5.0+ via subprocess (capture + encoding), pytest (testing)
**Storage**: JSON file in OS user config directory (settings persistence only; recordings are MP4 files)
**Testing**: pytest + QTest (Qt widget testing) + FFmpeg mock for unit tests
**Target Platform**: Windows 10+, macOS 12 (Monterey)+
**Project Type**: Desktop application (single window, no server component)
**Performance Goals**: Capture at 30 fps with < 5% CPU overhead on the recording thread;
output file available within 5 seconds of Stop press (per SC-002)
**Constraints**: No additional user-installed software required (FFmpeg bundled); offline-capable;
no authentication; macOS screen-recording permission handled by OS prompt
**Scale/Scope**: Single-user desktop app; one recording session at a time
